Projets

Application météorologique

Java · NetBeans · Git

À partir d'un code non fonctionnel, j'ai créé une station météo en console qui affiche température, pluie et vent selon des unités et un créneau horaire choisis.

Résultat : une station complète qui prend en charge plusieurs types de données.

Jeu de labyrinthe

JavaFX · Java · Git

J'ai réalisé la carte, ses textures, les déplacements du personnage, l'entrée et la sortie, puis les déplacements des monstres.

Résultat : un labyrinthe à 2 étages, avec monstres suivant une trajectoire et une sortie qui marque la victoire.

Comparaison d'arbres AVL et BST

Java · Python (matplotlib, pandas)

J'ai implémenté le parcours, l'équilibrage et les rotations d'arbres, puis un benchmark pour comparer les deux structures.

Résultat : temps d'exécution visualisés en boîtes à moustaches, avec taille des arbres paramétrable.

Visualisation statistique de données

Python (pandas) · SQL · C# · Gantt · Git

Projet d'équipe pour l'entreprise « Bon Pote » : transformer des données chiffrées en graphiques par zone géographique, avec suivi de projet sur diagramme de Gantt.

Résultat : un logiciel qui génère des graphiques pour visualiser des données écologiques.

Installation d'une machine virtuelle

VMware · Bash · Git

J'ai choisi un OS léger adapté à une configuration limitée, puis installé les outils de développement et configuré rôles et permissions.

Résultat : VM Debian 11 (Xfce) avec Git, VSCode et le langage FORTH.

Configuration d'un réseau virtuel

Bash · NEmu · VSCode · Markdown

J'ai installé NextCloud et OnlyOffice sur 2 serveurs, configuré 2 utilisateurs avec leurs groupes et permissions, et rédigé le guide d'installation.

Résultat : des machines qui communiquent entre elles et avec les serveurs, guide complet en anglais.

Site web « All In One Sport »

HTML · CSS

Site statique multipage respectant l'UX/UI et la validation W3C, adapté mobile et PC, conçu à partir d'une maquette.

Résultat : un site intuitif qui présente l'application pour sportifs de tous niveaux, fidèle à la maquette.

Base de données universitaire

SQL Server · WinDesign

Schéma, script de création et script de vérification d'un système scolaire : relations, jointures et principe du CRUD.

Résultat : une base propre avec données fictives (professeurs, étudiants, cours, emplois du temps).
